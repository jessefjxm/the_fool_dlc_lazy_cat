# 愚者DLC - 懒惰之猫
我非常喜欢愚者里的各类收集玩法：罪梦之猫系列、孤独症系列、旅行者系列。但是，肝起来太累了！
所以我整了一系列偷懒脚本，极大简化收集过程。

## 用法
把仓库里的脚本丢到整合包的 kubejs\server_scripts\ 目录下，例如：
D:\Games\Minecraft\.minecraft\versions\愚者 0.3.0\kubejs\server_scripts\

然后，执行 /reload 命令（如果你是管理员并且在游戏里），或者重新存档，或者重新开端，这些脚本就能生效。

## 效果
共同点：不需要佩戴特定道具，不需要使用特定技能
- 共振之狐：获取新的匹配物品（能作为 石磨配方：create:milling 或 粉碎轮配方：create:crushing 的原料），就自动添加记录
- 坚韧之猫：受到新类型的伤害，就自动添加记录
- 酿态之猫：获得新的BUFF，就自动添加记录
- 陪伴之狐：看向新的动物，就自动添加记录
- 拾魔之猫：获取新法术卷轴、升级法球，就自动添加记录
- 书龙之猫：获取有新附魔的附魔书（只能是附魔书，支持多个附魔），就自动添加记录
- 贪食之狐：破坏新的矿物方块，就自动添加记录
- 探险之狐：进入新的结构（无视高度），就自动添加记录
- 武器之狐：获取新的装备（近战武器、工具、远程武器、法术书），就自动添加记录
- 献祭之猫：获取新的遗物，就自动添加记录
- 血鸣之狐：获取新的匹配物品（能作为 营火配方：minecraft:campfire_cooking 的原料），就自动添加记录
- 元素之猫：击杀新的火系 / 深渊系 / 岩系生物，就自动添加记录（满5点亲和度）
- 孤独症：获取新唱片，进入新群系，就自动添加记录
- 旅行者：进入新群系，就自动添加记录，并且是7个维度同步添加
